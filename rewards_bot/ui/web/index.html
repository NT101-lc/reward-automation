The repo is private, so GitHub only shows releases with a token. Create a fine-grained token for this repo only, with Contents: Read-only. Windows encrypts the token (DPAPI) and it is never shown again. Leave it empty and click Save to delete it.

Chạy nhiều cửa sổ cùng lúc

Cửa sổ riêng (nên dùng): mỗi tài khoản có thư mục riêng trong data/profiles. Bấm Đăng nhập một lần cho mỗi tài khoản rồi chạy.

Gắn vào Edge đang mở: tự mở Edge với cổng debug và thư mục riêng, đăng nhập trong đó, rồi thêm tài khoản chế độ này với cổng tương ứng:

msedge.exe --remote-debugging-port=9222 --user-data-dir="C:\EdgeRewards1"

Own window (recommended): each account has its own folder in data/profiles. Click Log in once per account, then run.

Attach to an open Edge: open Edge yourself with a debug port and its own folder, log in there, then add an account in this mode with the matching port:

msedge.exe --remote-debugging-port=9222 --user-data-dir="C:\EdgeRewards1"

Hướng dẫn sử dụng

Đọc một lần là dùng được. Bấm từng mục để mở.

  1. Thêm tài khoản: trang Tài khoản → Thêm tài khoản. Mỗi tài khoản Microsoft một dòng.
  2. Đăng nhập (chỉ 1 lần): bấm Đăng nhập ở dòng đó. Cửa sổ mở 2 tab: đăng nhập ở tab Rewards, rồi xem tab bing.com góc phải phải là cùng tài khoản. Xong thì đóng cửa sổ.
  3. Kiểm tra: bấm Kiểm tra ở dòng tài khoản, bot tự chẩn đoán (không search). Kết quả từng mục (dòng [Kiểm tra] OK / WARN / FAIL kèm cách sửa) hiện ở trang Nhật ký.
  4. Chạy: chọn việc ở mục Việc bot sẽ làm khi chạy, rồi bấm Chạy (1 tài khoản) hoặc Chạy tất cả.

  • Daily Set, Keep earning: bấm từng thẻ, làm quiz và poll cơ bản.
  • Quests: làm từng bước của các quest nhiều bước ở trang Earn. Bước nào phải mở khóa bằng app Microsoft Rewards trên máy tính hoặc app điện thoại thì bot bỏ qua và ghi lý do vào nhật ký.
  • Search PC / Search Mobile: tìm đến khi đủ 90 / 60 điểm. Cứ 3 lượt đọc lại điểm; 6 lượt liền không được cộng thì dừng và ghi lý do.
  • Browse: lướt web cho Edge – Minutes (Edge Browsing Streak, 30 phút/ngày). Làm được, nhưng Rewards không tính phút ngay và đều: thường phải chạy lại 3–4 lượt trong ngày thì mới lên đủ 30/30. Mỗi lượt bot đọc số phút 10 phút một lần và ghi vào nhật ký, nên xem nhật ký là biết đã lên bao nhiêu. Nếu chạy nhiều lượt, nên tắt "Tự dừng khi không được tính phút" (mục con dưới Browse ở trang Tài khoản), vì lượt đầu thường chưa tăng và bot sẽ dừng sớm.
  • Visual Search: mỗi ngày tải 1 ảnh lên bằng nút camera của Bing Images (ảnh lấy ngẫu nhiên từ Bing).

  • Bing App – Check-in (Bing App Streak): mở app Bing trên điện thoại mỗi ngày.
  • Edge – Minutes (Edge Browsing Streak): nếu Browse chạy 3–4 lượt vẫn chưa đủ 30/30, tự dùng Edge đã đăng nhập tài khoản đó thêm một lúc.

Hai việc này giữ các chuỗi streak, giúp nhận dấu cho Stamp bonus.

Mỗi chuỗi streak (Bing Search, Daily Set, Bing App, Visual Search) có 7 ô cho 7 ngày. Làm đủ việc trong ngày thì ô hôm nay được tô. Giữ các chuỗi để nhận dấu; đủ 12 dấu thì nhận +1.000 điểm.

Ở trang Tổng quan: ô là ngày đã xong, ô là hôm nay chưa làm.

Microsoft Rewards cấm dùng bot. Tài khoản có thể bị khóa hoặc mất điểm. Bạn tự chịu rủi ro.

  1. Add an account: Accounts page → Add account. One row per Microsoft account.
  2. Log in (once): click Log in on that row. A window opens with 2 tabs: log in on the Rewards tab, then check that the bing.com tab shows the same account in the top right. Close the window when done.
  3. Check: click Check on the account row. The bot diagnoses itself (no searches). Each result (a [Kiểm tra] OK / WARN / FAIL line with how to fix it) shows up on the Log page.
  4. Run: pick the tasks under What the bot does on a run, then click Run (one account), Run all, or Do everything to do every task regardless of the switches.

  • Daily Set, Keep earning: opens each card and answers basic quizzes and polls.
  • Quests: works through the steps of multi-step quests on the Earn page. Steps that must be unlocked in the Microsoft Rewards desktop app or the phone app are skipped, with the reason written to the log.
  • Search PC / Search Mobile: searches until 90 / 60 points. Re-reads the points every 3 searches; after 6 searches in a row without points it stops and writes why.
  • Browse: browses the web for Edge – Minutes (Edge Browsing Streak, 30 min/day). It works, but Rewards doesn't count minutes right away or evenly: it usually takes 3–4 runs in a day to reach 30/30. Each run reads the minutes every 10 minutes and writes them to the log, so the log shows how far you got. If you run it several times, turn off "Stop when minutes aren't counted" (the sub-switch under Browse on the Accounts page), because the first run often shows no gain and the bot would stop early.
  • Visual Search: once a day, uploads one image (picked at random from Bing) with Bing Images' camera button.

  • Bing App – Check-in (Bing App Streak): open the Bing app on your phone every day.
  • Edge – Minutes (Edge Browsing Streak): if 3–4 Browse runs still don't reach 30/30, use Edge signed in to that account yourself for a while.

These two keep the streaks going, which earns stamps for the Stamp bonus.

Each streak (Bing Search, Daily Set, Bing App, Visual Search) has 7 boxes for 7 days. Finish the day's task and today's box fills in. Keep streaks going to earn stamps; 12 stamps give +1,000 points.

On the Overview page: is a finished day, is today, not done yet.

Create a task in Windows Task Scheduler with the project folder as the start folder, and this command (for the .exe: RewardsBot.exe --run-all --headless):

python -m rewards_bot --run-all --headless

It only runs while the app window is closed.

bing.com is logged in to the wrong account
Click Log in, log out on the bing.com tab, then log in again with the right account.
Searches don't earn points
Click Check. Try one search by hand on your phone or computer: if that doesn't count either, Microsoft has paused credit for that account for now.
"Profile đang mở trong một cửa sổ trình duyệt khác"
The profile is open in another browser window. Close the Edge window using that account's folder, then run again.
"không vào được … bỏ qua trang này"
Your network blocks that site (for example bbc.com). That's fine, the bot moves on to another site.
Need to send an error to someone
Log page → Copy, or send the file data/logs/<date>.log.

Log lines written by the bot stay in Vietnamese.

Where data is stored

data/profiles/
Each account's login session
data/points_history.json
Points per day (charts)
data/logs/
Logs, kept for 14 days

Only your Windows user can read the data/ folder, and it is never pushed to git.
Microsoft Rewards forbids bots. Accounts can be banned or lose points. Use at your own risk.

Cách mở trình duyệt
Mọi chương trình trên máy đều điều khiển được Edge qua cổng này. Chỉ mở Edge debug khi cần chạy bot, và không dùng --remote-debugging-address (sẽ lộ cổng ra mạng LAN).
Any program on this computer can control Edge through this port. Only open Edge in debug mode when you need the bot, and don't use --remote-debugging-address (it exposes the port to your LAN).
Tự đăng nhập lại (không bắt buộc)
Chỉ dùng khi phiên đăng nhập hết hạn. Mật khẩu được Windows mã hóa (DPAPI): chỉ tài khoản Windows này trên máy này giải mã được, app không bao giờ hiện lại. Nếu Microsoft hỏi mã xác minh, Authenticator hay CAPTCHA, bot dừng để bạn bấm Đăng nhập và tự làm.
Used only when the login session expires. Windows encrypts the password (DPAPI): only this Windows user on this computer can decrypt it, and the app never shows it again. If Microsoft asks for a verification code, Authenticator or a CAPTCHA, the bot stops so you can click Log in and finish it yourself.
